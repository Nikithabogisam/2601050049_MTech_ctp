# CO1

## Description

This folder contains eight Python programs designed to demonstrate different programming concepts and algorithms. The programs solve simple real-world problems such as managing student attendance, parking vehicles, handling an online shopping cart, sorting student records, searching for books, sorting numbers, finding the maximum subarray, and finding the closest pair of students.

## Programs

1. Student Attendance Management System
2. Parking Management System
3. Online Shopping Cart
4. Student Merge Sort
5. Books Binary Search
6. Quick Sort
7. Maximum Subarray
8. Closest Pair of Students
