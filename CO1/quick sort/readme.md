# Quick Sort

## Description

This project contains a Python program that uses the Quick Sort algorithm to arrange a list of numbers in ascending order. The program selects a pivot and divides the remaining values into smaller and larger groups before sorting them recursively.

## Algorithm

1. Start
2. Read a list of numbers from the user.
3. Check whether the list has zero or one element.
4. Select the first element as the pivot.
5. Place smaller or equal elements into the left list.
6. Place larger elements into the right list.
7. Apply Quick Sort recursively to both lists.
8. Combine the sorted left list, pivot, and sorted right list.
9. Display the sorted list.
10. Stop.

## Input

Enter numbers separated by spaces:

13 4 5 2 6 1 3

## Output

Original list: [13, 4, 5, 2, 6, 1, 3]

Sorted list: [1, 2, 3, 4, 5, 6, 13]
