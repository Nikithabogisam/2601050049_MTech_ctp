# Parking Management System

## Description

This project contains a Python program for managing a parking area with 100 parking slots. The system displays the number of available slots, handles vehicle entry and exit, assigns parking slots, records entry and exit times, and calculates the parking fee.

## Algorithm

1. Start
2. Set the total number of parking slots to 100.
3. Display the parking menu.
4. Check and display the number of available slots.
5. When a vehicle enters, check whether a parking slot is available.
6. Assign the first available slot and record the entry time.
7. When a vehicle exits, find its parking record.
8. Calculate the parking duration.
9. Calculate the parking fee.
10. Remove the vehicle from the parking records.
11. Update the available slots.
12. Stop when the user selects Exit Program.
