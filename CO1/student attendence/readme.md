# Student Attendance Management System

## Description

This project contains a Python program that manages student attendance records. It takes the total number of classes and attended classes for each student, calculates the attendance percentage, identifies students whose attendance is below 75%, finds the student with the highest attendance, and calculates the class average.

## Algorithm

1. Start
2. Read the number of students.
3. Enter the name, total classes, and attended classes for each student.
4. Calculate the attendance percentage.
5. Display the attendance details of each student.
6. Check which students have attendance below 75%.
7. Find the student with the highest attendance.
8. Calculate the class average attendance.
9. Display the final results.
10. Stop.

## Input

Enter number of students: 2

Student 1:
Name: nikitha
Total classes conducted: 6
Classes attended: 5

Student 2:
Name: jyothi
Total classes conducted: 6
