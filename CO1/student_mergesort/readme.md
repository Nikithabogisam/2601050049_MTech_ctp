# Student Merge Sort

## Description

This project contains a Python program that uses the Merge Sort algorithm to arrange students according to their marks. The program sorts the students in descending order and then identifies students who are eligible for a scholarship based on a minimum mark of 85.

## Algorithm

1. Start
2. Store the student names and their marks.
3. Divide the student list into two smaller parts.
4. Recursively divide the parts until each part contains one student.
5. Compare the marks while merging the smaller lists.
6. Arrange the students in descending order of marks.
7. Display the sorted student list.
8. Check which students have marks of 85 or above.
9. Display the students eligible for the scholarship.
10. Stop.

## Input

Student marks:

Anitha - 95  
Vivek - 83  
Lakshmi - 67  
Ramesh - 97  
Kumar - 85

Scholarship cutoff: 85

## Output

Students in descending order of marks:

Ramesh 97  
Anitha 95  
Kumar 85  
Vivek 83  
Lakshmi 67

Students eligible for scholarship:

Ramesh 97  
Anitha 95  
Kumar 85
