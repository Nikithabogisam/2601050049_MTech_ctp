# Maximum Subarray

## Description

This project contains a Python program that finds the continuous part of a sequence of numbers having the maximum possible sum. The program keeps track of the current sum and the maximum sum while processing the sequence.

## Algorithm

1. Start
2. Read a sequence of numbers.
3. Initialize the current sum and maximum sum.
4. Process each number in the sequence.
5. Decide whether to continue the current subarray or start a new one.
6. Update the current sum.
7. Compare the current sum with the maximum sum.
8. Store the starting and ending positions of the best subarray.
9. Extract the maximum subarray.
10. Display the original sequence, maximum subarray, and maximum sum.
11. Stop.

## Input

Enter numbers separated by spaces:

1 21 31 2 7 3 8 14

## Output

Original list: [1, 21, 31, 2, 7, 3, 8, 14]

Maximum subarray: [1, 21, 31, 2, 7, 3, 8, 14]

Maximum sum: 87
