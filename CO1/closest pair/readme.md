# Closest Pair of Students

## Description

This project contains a Python program that finds the two students who are closest to each other based on their positions on a two-dimensional coordinate system. The program calculates the Euclidean distance between every possible pair of students and identifies the pair with the smallest distance.

## Algorithm

1. Start
2. Read the number of students.
3. Enter each student's name and X and Y coordinates.
4. Store the student information.
5. Compare every possible pair of students.
6. Calculate the distance between each pair using the distance formula.
7. Keep track of the smallest distance found.
8. Store the names of the two closest students.
9. Display the closest students and their distance.
10. Stop.
