# Online Shopping Cart

## Description

This project contains a Python program that manages an online shopping cart. The system allows users to add products, remove products, change product quantities, display the cart, and generate a final bill. It also calculates the subtotal, discount, GST, and final amount.

## Algorithm

1. Start
2. Create an empty shopping cart.
3. Display the shopping cart menu.
4. Add a product with its price and quantity.
5. Remove a product when requested.
6. Change the quantity of an existing product.
7. Display the products currently present in the cart.
8. Calculate the subtotal of all products.
9. Apply the discount according to the subtotal.
10. Calculate GST.
11. Display the final bill.
12. Exit the program when the user selects Exit.
