# Books Binary Search

## Description

This project contains a Python program that uses the Binary Search algorithm to find a particular book number in a library containing book numbers from 1 to 1,000,000. Binary Search repeatedly divides the search range into two parts to find the required book efficiently.

## Algorithm

1. Start
2. Create a list of book numbers from 1 to 1,000,000.
3. Set the lower boundary to the first position.
4. Set the upper boundary to the last position.
5. Find the middle position.
6. Compare the middle value with the required book number.
7. If the value matches, return its position.
8. If the required number is larger, search the right half.
9. If the required number is smaller, search the left half.
10. Continue until the book is found or the search range becomes empty.
11. Display the result.
12. Stop.

## Input

What book do you want to find:

120000

## Output

book is at: 119999
